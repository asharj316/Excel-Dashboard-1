# Excel-Dashboard-1
Project Title: Automated Sales Dashboard (Excel + VBA Macros)
Overview

A dynamic and automated Sales Dashboard built in Microsoft Excel using Pivot Tables, Charts, and VBA Macros to streamline sales data analysis. This project demonstrates advanced Excel skills, including automation, interactivity, and data visualization.
Key Features

✅ Interactive Dashboard Controls:

    Macro-powered buttons for one-click updates (e.g., Refresh Data, Generate Reports).

    Slicers & Dropdowns for filtering by Region, Product, and Time Period.
    ✅ Automated Processes:

    VBA scripts to clean data, refresh PivotTables, and export reports.

    Dynamic charts that update based on user selection.
    ✅ Key Metrics Tracked:

    Total Sales, Profit Margins, Top-Performing Products, Regional Performance.

    Conditional formatting for performance alerts (e.g., low stock, declining sales).

Tools & Technologies

    Microsoft Excel (PivotTables, Advanced Charts, Slicers)

    VBA (Macros) for automation and interactivity.

How to Use

    Download the .xlsm (macro-enabled) file.

    Enable Macros when prompted (required for interactivity).

    Use buttons/slicers to filter data and generate reports.
